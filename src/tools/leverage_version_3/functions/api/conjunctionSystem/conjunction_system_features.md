# Conjunction System Features

+ In configuration panel : Trading And Control > it shows : Active System Mode: Conjunction System and in 'auto entry from signal ' checkbox the drop down becomes "N/A, see system panel".
+ Utilizes available classic systems into conjunction system by abstracting their signals logically.
+ Each selected system from classic system has it's own panel of configuring it's parameters.
+ Unique 'Conjunction system panel' contains each active system that is being used for entry with changeable data source.
+ when there is one active system in conjunction system it behaves as a classic system taking decision on crossover state.
+ when there are two or more they trigger entry signal when they all correlate or exactly align into same direction.
+ **Self Replication Mode**: Allows replication of a single system (e.g., Supertrend Regime) up to a total of 3 times. These behave as independent systems allowing distinct data source parameters. The naming convention applies `- Alpha`, `- Beta` and `- Delta` to uniquely identify each cloned configuration.
